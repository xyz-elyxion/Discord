If you're here, it probably means you're trying to learn how to create Limey V1 plugins. You've come to the right place!

If you're actually just looking for Limey V1 download instructions, please [visit our main site](https://limey-discord.onrender.com) instead!

This documentation will cover topics like:
- How to install Limey V1 from source, the prerequisite for adding custom plugins
- How to setup your development environment
- The plugin structure and all the available plugin APIs
- How to reverse engineer and understand Discord code to find which functions you need to use or patch
- And much more!
