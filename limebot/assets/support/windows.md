> ⚠️ Do not run the installer as Administrator

Download [Limey V1Installer.exe](https://github.com/Limey V1/Installer/releases/latest/download/Limey V1Installer.exe). Run it and a graphical interface should open

If this installer does not open, download [Limey V1InstallerCli.exe](https://github.com/Limey V1/Installer/releases/latest/download/Limey V1InstallerCli.exe) instead.
Run it and a terminal window will open. Follow the instructions in it
