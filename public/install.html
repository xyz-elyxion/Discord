Install steps — no Node.js required

  1. Download the Limey V1 Installer for your platform below.
  2. Windows: just run the .exe — it opens a graphical installer. macOS: run ./LimeyV1Installer-cli-macos-* in Terminal (use chmod +x first; arm64 = Apple Silicon). If macOS blocks it with “can’t be opened” or “damaged”, first run xattr -d com.apple.quarantine LimeyV1Installer-cli-macos-* — it’s unsigned, so Gatekeeper quarantines it. Linux: chmod +x LimeyV1Installer-cli-linux && ./LimeyV1Installer-cli-linux.
  3. Pick your Discord install, choose Install Limey V1, done.
  4. Restart Discord — Limey V1 appears in Settings. Use Uninstall to remove it.
Installer for Windows (GUI) Windows (CLI) macOS (Apple Silicon) macOS (Intel) Linux Alternative: manual .zip package Get the Browser Extension instead

To remove later: delete the injected app folder in Discord's resources directory and restore app.asar from app.orig.asar. Works on any Discord branch: Stable, Canary or PTB. Windows · macOS · Linux.
