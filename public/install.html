Discord Desktop App

Inject Limey V1 directly into the Discord desktop client, classic client-mod style. The backend builds and serves everything — the installer runs on your machine.

Checking build status…

Install steps

  1. Install Node.js and enable pnpm (corepack enable pnpm).
  2. Clone the repository and install dependencies: git clone → pnpm install.
  3. Build, then inject: pnpm build followed by pnpm inject.
  4. Restart Discord — Limey V1 appears in Settings.
Back to Download Install API (JSON)

To remove later, run pnpm uninject. Works on any Discord branch: Stable, Canary or PTB. Windows · macOS · Linux.
