Discord client mod · Web version

Discord, but limey.

Limey V1 is a lightweight client mod that injects 100+ plugins into Discord's web app — custom themes, QuickCSS, platform indicators, message tools and much more. No Nitro required, no telemetry, GPL‑3.0 open source.

Install Userscript How to install

Requires a userscript manager like Tampermonkey or Violentmonkey.

Features

100+ built-in plugins

Message logger, silent typing, platform indicators, Spotify controls, hidden channel viewer and many more — all toggleable. Browse the full list →

Custom CSS & themes

Built-in QuickCSS editor and full theme support, including BetterDiscord theme compatibility.

Privacy first

Blocks Discord analytics and crash reporting out of the box. No telemetry of any kind.

Lightweight

Written in TypeScript and bundled with esbuild. Fast startup, tiny footprint.

Open source

Fully GPL-3.0 licensed. Audit the code or contribute on GitHub.

Works everywhere

Runs on Discord Stable, Canary and PTB in any Chromium browser or Firefox.

Install in 3 steps

  1. Install a userscript manager. Get Tampermonkey or Violentmonkey for your browser.
  2. Download Limey V1. Click the install button above, or grab dist/LimeyV1.user.js directly. Your userscript manager should offer to install it automatically.
  3. Open Discord. Head to discord.com/app and reload. Limey V1 injects before the app boots — you'll see it in Settings.

Client modifications technically violate Discord's Terms of Service. No users have ever been banned for simply using one, but use common sense and don't run abusive plugins.
