Discord client mod · Web version

Discord, but limey.

Limey V1 is a lightweight client mod that injects 100+ plugins into Discord's web app — custom themes, platform indicators, message tools and much more. No Nitro required, no telemetry, GPL‑3.0 open source.

Install Limey V1 Browse plugins

Browser extension or desktop inject — pick your install method.

Features

100+ built-in plugins

Message logger, silent typing, platform indicators, Spotify controls, hidden channel viewer and many more — all toggleable. Browse the full list →

Custom CSS & themes

Full theme support, including BetterDiscord theme compatibility.

Privacy first

Blocks Discord analytics and crash reporting out of the box. No telemetry of any kind.

Lightweight

Written in TypeScript and bundled with esbuild. Fast startup, tiny footprint.

Open source

Fully GPL-3.0 licensed.

Works everywhere

Runs on Discord Stable, Canary and PTB in any Chromium browser or Firefox.

Install in 3 steps

  1. Download the extension. Grab LimeyV1-Extension.zip and unzip it.
  2. Load it in your browser. Chrome/Edge: open chrome://extensions, enable Developer mode, click "Load unpacked" and select the unzipped folder. Firefox: open about:debugging and load the extension temporarily.
  3. Open Discord. Head to discord.com/app and reload. Limey V1 injects before the app boots — you'll see it in Settings.

Prefer the Discord desktop app? See the download page for the desktop inject method.
