⬇️ Download Limey V1 🧩 Browse plugins 📜 Community rules 💬 Open the Discord server

Verification setup

Add interactive verification & rules to your own server: pick a server where you have Manage Server and the Limey bot is present (invite the bot if it isn't).

Rules editor

Write your server's rules here — the bot posts them as a read-only card in the rules channel. Markdown works (**bold**, headings with #, lists). Leave empty to remove the card.

Counting game setup

Pick a text channel and the bot runs a counting game there: members count up one number per message. Wrong numbers or double-counting reset the count, and the record is saved.

Welcomer setup

The bot greets new members in a channel you pick. Placeholders: {user} mention, {username}, {server}, {count} member count.

Leveling setup

Members earn XP by chatting (up to 30 XP per message, 1 minute cooldown) and level up. Pick a channel for level-up announcements and watch the leaderboard fill up.

Leaderboard

Pick a server to load the leaderboard.

Autoroles setup

New members automatically get the roles you pick here the moment they join.

Reaction roles setup

Members react with an emoji anywhere in the server to get the matching role — remove the reaction to lose it. Use a raw emoji, or the emoji ID for custom emoji.

No mappings yet.

Starboard setup

Messages that reach the reaction threshold get mirrored into your starboard channel with a live count.

Suggestions setup

Every member post in the chosen channel gets 👍 / 👎 vote reactions added automatically.

How it works for your members

1. The bot posts a verification card in your chosen channel and keeps it read-only.
2. Limey V1 users get a native in-client card via the InteractiveVerification plugin.
3. Everyone else uses the website: Discord login → 3-round human challenge → verified.
4. Verified members get your role.
