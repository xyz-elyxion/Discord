Drop plugin example screenshots here — they appear automatically on
limey-discord.onrender.com/plugins/ at the top of each plugin's card.

Naming: <PluginName>.<number>.<ext>

  <PluginName>  exact plugin name from /plugins.json (case-sensitive,
                spaces/etc are fine — e.g. "Better Folders.1.png")
  <number>      1 for the first image; add 2, 3 ... up to 5 for a click-through
                slideshow on the card
  <ext>         .webp .png .jpg or .gif  (.webp preferred, ~16:10 looks best)

Examples:
  AccountChecker.1.webp
  Better Folders.1.png
  Better Folders.2.png

Plugins without an image here simply show without one — nothing else changes.
