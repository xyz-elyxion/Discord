Maintenance

Stable LTS

A frozen stable snapshot with a long support window — security and crash fixes only, never a mid-support feature churn. The installer and the in-app updater both stay inside the channel: get it with the CLI installer command below.

LimeyV1Installer-cli --install --channel lts ships today · frozen snapshot · pin status unknown
Pre-release

Release Candidate (RC)

Feature-complete builds of the next stable version, nearly-identical downstream quality already reviewed — folded into stable once clean. Published once per release cycle; the installer and updater stay in-channel, and pre-releases are never silently swapped for stable builds.

LimeyV1Installer-cli --install --channel rc per release cycle · publish status unknown
Pre-release

Beta

Public pre-release accumulating feature batches for the next version — a middle ground between RC rigor and dev-build bleeding edge, for curious users who accept some breakage. Frozen per feature batch like RC.

LimeyV1Installer-cli --install --channel beta per feature batch · publish status unknown

Host channel: Limey V1 supports every Discord desktop branch — Stable, PTB, Canary and Development. The installer detects everything automatically; if you have multiple clients installed, download the CLI installer above and point it at one branch:

Other ways to run Limey V1

Recommended

Browser Extension

Load Limey V1 as a real browser extension. Works with discord.com in any Chromium browser or Firefox.

  1. Download the extension zip below and unzip it.
  2. Chrome/Edge: open chrome://extensions, enable Developer mode, click Load unpacked, select the unzipped folder.
  3. Firefox: open about:debugging#/runtime/this-firefox, click Load Temporary Add-on, pick the unzipped manifestv2.json.
  4. Open discord.com/app and reload.
Download Extension (.zip) Chromium · Firefox

Userscript

Run Limey V1 in the browser via Tampermonkey, Violentmonkey or another userscript manager — no extension folder needed. Just install the script and open Discord in your browser.

  1. Install a userscript manager (Tampermonkey, Violentmonkey, etc.) in your browser.
  2. Click the install button below — your userscript manager will pick it up automatically.
  3. Open discord.com/app and reload.
Install Userscript Get the Theme (.user.css) Chromium · Firefox · Safari (Tampermonkey)
