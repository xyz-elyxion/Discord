Get Limey V1

Pick your install method.

Two ways to run Limey V1 — pick whichever fits how you use Discord.

Browser Extension

Load Limey V1 as a real browser extension. Works with discord.com in any Chromium browser or Firefox.

  1. Download the extension zip below and unzip it.
  2. Chrome/Edge: open chrome://extensions, enable Developer mode, click Load unpacked, select the unzipped folder.
  3. Firefox: open about:debugging#/runtime/this-firefox, click Load Temporary Add-on, pick the unzipped manifestv2.json.
  4. Open discord.com/app and reload.
Download Extension (.zip) Chromium · Firefox

Discord Desktop App

Inject Limey V1 directly into the Discord desktop client, classic client-mod style. No building required — the backend serves the ready-built package. Windows · macOS · Linux.

Download Installer for Windows (GUI) Download Desktop Package (.zip) Desktop Install Guide Restart Discord after installing — Limey V1 appears in Settings. To remove later, run pnpm uninject.

Client modifications technically violate Discord's Terms of Service. No users have ever been banned for simply using one, but use common sense and don't run abusive plugins. Both methods provide the same plugins and features.
