Official SDK · v1.0.0

Connect your bot to Limey V1

Give your Discord bot Limes economy support, the community ban registry, plugin data, invite lookups and platform status — with one import and zero dependencies.

🍋 One import, no install

The SDK is served straight from this site as a pure ES module. Import it by URL from Node 18+, a serverless function, or any bundler that resolves remote ESM. No npm account, no build step, no API key.

// Node 18+, ESM (add "type": "module" to your package.json) import { LimeyV1 } from "https://limey-discord.onrender.com/sdk/index.js"; const limey = new LimeyV1(); // your bot's ready handler client.on("ready", async () => { const banner = await limey.status.get(); if (banner.active) console.log("[limey]", banner.message); });

Prefer npm? pnpm add @limeyv1/sdk once published — the API is identical. Self-hosting Limey? Point baseUrl at your own instance instead.

What your bot can do

limey.limes

Full Limes economy: wallets, daily claims, message/voice/stream/game activity, perk tiers (Seedling / Grove / Orchard), trials and subscriptions.

await limey.limes.claimDaily(userId)

limey.bans

Check any Discord user against the official Limey V1 ban registry — keep trust-sensitive actions aligned.

await limey.bans.isBanned(userId)

limey.plugins

List or look up community plugins for /plugins commands and inline embeds.

await limey.plugins.list()

limey.tools

Resolve Discord invites and guild widgets without your own Discord REST token.

await limey.tools.lookupInvite(code)

limey.status

Surface platform outages and rate-limit banners inside your bot's logs or status page.

await limey.status.isActive()

limey.sentinel

Complete the Limey Sentinel proof-of-work captcha in-process for gated flows.

await limey.sentinel.solveToken()

Limes economy walkthrough

All rates, streaks, caps and cooldowns are enforced server-side. You forward activity, the platform does the math. Batch messages instead of firing per-message hits — the server counts per 25 messages.

// wallet overview const wallet = await limey.limes.wallet(userId); // → { balance: 1_250, streak: 4, tier: "grove", multiplier: 1.0, nextDailyAt ... } // daily claim (server 429s if too early — err.code === "rate_limited") const claim = await limey.limes.claimDaily(userId); // batch message activity from your gateway await limey.limes.countMessages(userId, 25); // voice / stream / game minutes, awarded per 15-minute block await limey.limes.countVoice(userId, 15); // perk tiers const { tiers } = await limey.limes.tiers(); await limey.limes.startTrial(userId, "seedling"); await limey.limes.subscribe(userId, "orchard");

Error handling that doesn't crash your bot

Every failure throws a LimeyV1Error with a stable machine-readable code. Retries on 429/5xx are automatic; every request has a 15s timeout.

import { LimeyV1, LimeyV1Error } from "https://limey-discord.onrender.com/sdk/index.js"; try { await limey.limes.claimDaily(userId); } catch (err) { if (err instanceof LimeyV1Error && err.code === "rate_limited") { // cooldown — err.data.nextDailyAt tells you when } }
codemeaning
network_errorfetch failed / timed out (status = 0)
rate_limitedHTTP 429 after retries
server_errorHTTP 5xx after retries
api_errorother non-2xx (err.data holds the body)
not_foundunknown plugin / bot-state key / lookup
