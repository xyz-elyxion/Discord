🔍 Account Checker

Curious how established a Discord account is? Paste an ID, a @mention or a profile link and this tool derives the account creation date from the ID itself. For the full picture — badges, Nitro and profile investment — use the AccountChecker plugin that ships with Limey V1.

🕸 Friend graph visualiser

Turn friend lists into a living social web. Run /friendgraph in Discord with the AccountChecker plugin to copy your friends as JSON, paste it here, and drag nodes around. Paste several people's exports to reveal shared friends between groups — nodes merge by name.

🏰 Server graph visualiser

The same living graph, but for servers. Run /servergraph in Discord with the AccountChecker plugin to copy your server names as JSON, paste it here, and drag nodes around. Paste several people's exports to surface the servers you all share — overlap pops green. Only server names are exported, never IDs, members or channels.
