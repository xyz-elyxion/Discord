How do I install a downloaded plugin?
  1. Download the .zip for the plugin you want.
  2. Unzip it so the folder lands in src/userplugins/ inside your Limey V1 checkout (the archive already contains one folder per plugin).
  3. Rebuild and reinject: pnpm build then pnpm inject, and restart Discord.
  4. Open Settings → Plugins, review the permissions the plugin asks for, then enable it.

⚠️ Plugins run with full client privileges. Built-in downloads come from this repository, but community submissions are not audited — read the code before you enable anything.
